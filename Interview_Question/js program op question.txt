function test() {
  var x = 20;
  console.log(x);
}

test();

Output:

Copy
Edit
20
10
Explanation:
Inside test, a new local variable x is declared (var x = 20). It shadows the global x. So console.log(x) inside test() logs 20.
Outside the function, the global x is untouched, hence console.log(x) logs 10.
